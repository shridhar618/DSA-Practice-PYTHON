# DSA Practice: Python Basics

Beginner data structures and algorithms practice in Python, focused on arrays and linked lists.

## Contents

- **Array:** min and max, second largest, smallest element, duplicates, frequency count, reversal, palindromes, Fibonacci, factorial, bubble and selection sort, pattern printing, HackerRank and TCS-style problems
- **Linked List:** traversal

## Running

```bash
python3 Array/bubble_sort.py
```
